# ADR 0001: ощущение мобильного приложения и PWA

Дата: 19.11.2026. Статус: принято.

## Контекст
Покупатели заходят в основном с телефона. Нужны мгновенный отклик на нажатие, переходы без белой вспышки, быстрый «назад» и установка на экран, без тяжёлых библиотек.

## Решение
- `src/features/app-feel/`: pressed-состояния (`.press`, кнопки, чипы), вход страницы 180 мс в `app/template.tsx` (на «Назад» без анимации, при reduced motion только fade), полоса загрузки 2px только если переход дольше 150 мс, `IntentLink` с prefetch по намерению.
- Шапка, плашка стейджа и тосты живут в `app/layout.tsx` и не перемонтируются.
- `experimental.staleTimes: { dynamic: 30, static: 300 }` для мгновенного «назад».
- PWA: `app/manifest.ts` (standalone, иконки 192/512/maskable из знака MF), apple-touch-icon, `viewport-fit=cover`, safe-area отступы у закреплённых панелей.
- Сервис-воркер `public/sw.js` без библиотек: статика `/_next/static`, шрифты и 3D-модели cache-first; HTML network-first с `/offline`; не кешируются `/api`, `/admin`, `/order`, `/checkout` и все не-GET запросы. Кеш по ID сборки (`APP_VERSION`), старые удаляются при активации. `NEXT_PUBLIC_SW=off` снимает воркер.

## Последствия
- Новых зависимостей нет.
- После смены версии воркер обновляется при следующем визите; при проблемах выключатель `NEXT_PUBLIC_SW=off` и пересборка.
