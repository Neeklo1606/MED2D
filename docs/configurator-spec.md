# Спецификация конфигуратора (черновик к утверждению)

Источник: раздел 2 мастер-промпта. Макет Figma "Конфигуратор итог" агенту недоступен (нет Figma MCP), прототип `data/prototype-configurator.html` в репозиторий не передан. Всё ниже нужно сверить с макетом.

## 1. Сущности
- **Слот** (`slot`): `base < feet < bottom < top < coat < head < accessory`. z-index = индекс в этом списке × 10.
- **Вещь в образе:** `{ productSlug, colorSlug, size | null }`. В слоте не больше одной вещи.
- **Образ:** `{ gender: "f" | "m", slots: Partial<Record<Slot, WornItem>>, zoom: 1..3, pan: {x,y} }`.

Соответствие товаров слотам:
| Товар | Слот | Размеры |
|---|---|---|
| Халат | coat | из вариантов |
| Рубашка-анорак, Футболка оверсайз | top | из вариантов |
| Брюки-джоггеры | bottom | из вариантов |
| Шапочка, Докерка | head | без размера (уточнить) |
| Сабо | feet | 36-45 |
| Шнурок, Шопер, Термокружка | accessory | без размера |

Вопрос: анорак и футболка в одном слоте `top` (одна заменяет другую). Если футболку нужно носить под анорак, нужен отдельный слот `under`. В `blockers.md`.

## 2. Сценарии
1. **Примерить** вещь: кладёт её в слот (заменяя прежнюю), цвет = выбранный в карточке (по умолчанию первый доступный), размер = выбранный или `null`. Кнопка в карточке становится "Снять" (белая).
2. **Смена цвета** у надетой вещи: слой меняется сразу, crossfade ≤ 200 мс (0 мс при `prefers-reduced-motion`). Цвет без остатка (если `track_stock`) приглушён, `aria-disabled`, подпись "нет в наличии".
3. **Размер:** чипы из вариантов БД. Выбранный: чёрная заливка.
4. **ИТОГО:** сумма цен надетых вещей (цены с сервера). Строка: название, цена, × (снять), иконка "в корзину" (добавить одну вещь; без размера: подсветить карточку и проскроллить к ней).
5. **Добавить весь образ:** все вещи с размерами должны иметь размер. Иначе незаполненные карточки подсвечиваются, скролл к первой, фокус на группу размеров. Вещи с `price_pending` не добавляются, показывается сообщение.
6. **Снять всё:** очищает слоты, гендер остаётся.
7. **Модель Ж/М:** меняет базовый слой и все слои вещей на соответствующий гендер. Состав образа сохраняется.
8. **Зум:** кнопки +/− (шаг 0.25, 1..3), pinch на тач, drag при zoom > 1, двойной тап = сброс.
9. **URL:** `?g=f&top=anorak.pink.M&bottom=joggers.pink.M` (`slot=product.color[.size]`). Обновление через `replaceState` с debounce 300 мс. При загрузке: парс, валидация по каталогу с сервера, невалидные части отбрасываются молча.

## 3. Отрисовка (LayerRenderer)
```ts
interface LayerRenderer {
  render(look: Look, catalog: CatalogIndex): void;
  preload(urls: string[]): Promise<void>;
  setZoom(zoom: number, pan: { x: number; y: number }): void;
}
```
Реализация v1: `ImageLayerRenderer` (стек абсолютных `<img>` на одном холсте). Путь слоя: `media/layers/{gender}/{productSlug}/{colorSlug}.webp`.
Фолбэк: если слоя для цвета нет, берётся белый слой + `mask-image` с тем же PNG + `background-color: hex` + `mix-blend-mode: multiply`.
Предзагрузка: слои текущего образа (high priority), остальные цвета надетых вещей лениво (`requestIdleCallback`).

## 4. Мобильная версия (проект агента)
- Шапка → модель на всю ширину (Ж/М слева снизу, зум справа снизу поверх фото) → табы категорий (Верх, Низ, Халат, Голова, Обувь, Аксессуары, sticky) → горизонтальная лента карточек со scroll-snap.
- Нижняя фиксированная панель "ИТОГО 9 200 ₽ · Добавить образ", тап по сумме раскрывает bottom sheet со списком надетых вещей.
- Тач-цели ≥ 44 px; проверка 360/375/390/414.

## 5. Состояние
Zustand store `useLook` (образ) + `useCart` (persist в localStorage). Каталог, цены и остатки: серверный компонент `/catalog` + `GET /api/catalog` (revalidate 60 c).

## 6. Тесты
- Vitest: сериализация/парсинг URL, замена в слоте, валидация размеров, сумма.
- Playwright: собрать образ → поменять цвет → поделиться ссылкой → перезагрузить → образ тот же → добавить образ в корзину (375 и 1440).
