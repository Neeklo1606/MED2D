# Дизайн-токены (ПРИБЛИЗИТЕЛЬНЫЕ)

Значения сняты по текстовому описанию макета, не из Figma Dev Mode. После доступа к файлу (или экспорта фрейма "Конфигуратор итог" в PNG 1440) значения сверяются и правятся только в `src/styles/tokens.css`.

| Токен | Значение | Где |
|---|---|---|
| `--color-bg` | `#EDEDEF` | фон страницы (светло-серый) |
| `--color-surface` | `#FFFFFF` | карточки |
| `--color-text` | `#0B0B0C` | основной текст, кнопка "Примерить", выбранный размер |
| `--color-muted` | `#6B6D73` | подписи |
| `--color-line` | `#DCDDE1` | разделители, обводки |
| `--color-accent` | `#1A3CFF` | блок ИТОГО, кнопка Ж, слово КАПСУЛУ, обводка Корзины |
| `--color-brandmark` | `#E3E4E8` | крупный знак бренда за моделью |
| `--radius-sm/md/lg/pill` | 8 / 14 / 22 / 999 px | чипы / миниатюры / карточки и ИТОГО / кнопки |
| `--tap-min` | 44 px | тач-цели |

## Шрифты
| Роль | Сейчас | Статус |
|---|---|---|
| Заголовки (широкий жирный гротеск, капс) | Unbounded Variable (OFL, кириллица), self-hosted `/public/fonts` | временный аналог, шрифт макета неизвестен (blockers) |
| Текст | Inter Variable (OFL, кириллица), self-hosted | временно |

`font-display: swap`, subset кириллица + латиница через `unicode-range`.

## Цвета товаров (свотчи, черновик)
голубой `#8FB8E8`, тёмно-синий `#1D2A4D`, изумрудный `#1F8A70`, синий `#2D5BE3`, розовый `#F2A7C3`, белый `#FFFFFF`, серый `#9A9CA3`, чёрный `#111111`, серебристый `#C7C9CE`. Нужны точные HEX или Pantone от заказчика/фабрики.
