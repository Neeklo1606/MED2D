# QA MEDFORM 23.11.2026: критические e2e-тесты

База: ветка `claude/magical-maxwell-scafo1`, коммит 8e69567. Стенды: локальная прод-сборка (`pnpm build && pnpm start -p 3400`, без БД) и живой стейдж https://med.neeklo.ru (только чтение, заявки не отправлялись; стейдж за время прогона передеплоился как минимум один раз).

## Как запускать

```bash
pnpm build && pnpm start -p 3400            # в другом терминале
node tests/e2e/run.mjs http://localhost:3400  # всё: 375×812 (isMobile, touch) и 1440×900
node tests/e2e/run.mjs https://med.neeklo.ru  # не-локальный адрес = read-only, заявка не отправляется
# опции: --only=health,configurator,resilience,pages,overflow  --viewports=375,1440  --out=<dir>  --allow-submit  --headed
```

Playwright берётся из `/opt/node22/lib/node_modules/playwright` (запасной вариант `require("playwright")`), новых зависимостей нет. Chromium с `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`, `reducedMotion: reduce` (без вступительного оборота, кадры стабильны), service worker заблокирован. Таблица pass/fail в консоли, `results.json` и скриншоты в `artifacts/qa/<стенд>/`, код выхода 1 при падении.

### Предлагаемое исправление №1 (P0)
В `ThreeRenderer.tsx` обернуть каждый `<Model>` (строка ~222–225) в маленький error boundary (класс-компонент), который при ошибке рендерит `null` и вызывает `useGLTF.clear(src)`, чтобы повтор был возможен. Дополнительно в `Configurator.tsx` вокруг `<ThreeRenderer>` (строка 147) boundary с фолбэком на `PhotoRenderer`. Тот же boundary нужен на карточке товара (`src/shop/ProductView.tsx`, `<ThreeRenderer>`). Регрессионный тест уже есть: группа `resilience`.

Файлы из баг-листа (`Configurator.tsx`, `ThreeRenderer.tsx`, `src/shop/*`) сейчас правят другие агенты, поэтому в этой ветке исправлений в коде продукта нет; изменения только в `tests/e2e/`, этом отчёте и `artifacts/qa/`.

## Замечания без падений
- На стейдже после деплоя у GLB появились `?v=<хэш>` и `Cache-Control: public, max-age=31536000, immutable`; до деплоя был `max-age=0`.
- Без БД `/api/cart/quote` отвечает 503: корзина пишет «Не удалось обновить цены…», «Оформить заявку» неактивна. Для локальной сборки без БД это ожидаемо, тест это проверяет.
- `pnpm start` предупреждает, что `next start` не работает с `output: "standalone"`; на деле работает, на стейдже используется `server.js`.
