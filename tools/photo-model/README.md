# Фото-модель конфигуратора

`source-f.webp`: исходное фото (женская модель, вид спереди и сзади на одном листе, прозрачный фон).

`segment.py` режет лист на виды и строит для каждой вещи слой тени (`*-shade.webp`) и маску (`*-mask.png`):
кожа и волосы определяются по тёплому оттенку и насыщенности с морфологической очисткой, ткань делится на
верх / брюки / сабо по горизонтальным линиям (подол, низ брюк) и линии шеи. Параметры линий в `views`.

```bash
python3 -I tools/photo-model/segment.py tools/photo-model/source-f.webp public/photo-model/f
```

На сайте слой тени кладётся поверх фото, а цвет вещи накладывается через `mask-image` + `mix-blend-mode: multiply`
(`src/configurator/renderers/PhotoRenderer.tsx`). Для мужской модели нужен такой же лист `source-m.webp`.
